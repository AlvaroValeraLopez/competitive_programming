# Competitive programming

Soluciones a retos de programación de varias fuentes, y una web que las explica paso a paso.

| Carpeta | Qué hay |
| --- | --- |
| `project_euler/` | Soluciones en JavaScript a los problemas de [Project Euler](https://projecteuler.net) |
| `exercism/` | Soluciones en C al recorrido de [Exercism](https://exercism.org) |
| `acepta_el_reto/` | Soluciones a los problemas de [Acepta el reto](https://aceptaelreto.com) |
| `hacker_rank/` | Soluciones a los retos de [HackerRank](https://www.hackerrank.com) |
| `web/` | **Retos, paso a paso**: la web que explica las soluciones, con la matemática, la algoritmia y la implementación que hay detrás ([README](web/README.md)) |
| `videos/` | Los vídeos de la web, generados con código con Manim y verificados con tests ([README](videos/README.md)) |
| `plataforma-educativa/` | Diseño de una plataforma para alumnos y profesores de matemáticas y ciencias, todavía sin código ([README](plataforma-educativa/README.md), [esquema DBML](plataforma-educativa/esquema.dbml), [modelo de datos](plataforma-educativa/modelo-datos.md), [visor del esquema](plataforma-educativa/visor/README.md)) |
